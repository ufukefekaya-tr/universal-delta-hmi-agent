## Tek yazı sahibi ve hidden conversion riski

- **Gözlem / kök neden:** Engineering unit'i numeric'in inline yazısında, ayrı text object'te ve inherited `UnitTextLenN` native caption'da aynı anda göstermek çift birim üretebilir. `ShowUnit=0` yalnız görünürlüğü kapatır; UnitSrc/UnitDisplay/percent/custom conversion metadata'sının identity olduğunu kanıtlamaz.
- **Etki:** Preview açık ve tek yazılı görünürken native aday farklı bir unit yazısı veya farklı numeric değer temsil edebilir. Caption'ın yeri/fontu native `UnitDirection` veya enum tahminiyle üretilirse kavramsal ve native sözleşme ayrışır.
- **Karşı görüş:** Embedded vendor unit meşru olabilir; raw record preservation onun placement veya conversion semantiğini kalibre etmez. Caption helper'ını tam unit compiler saymak ayrı yetkileri birleştirir.
- **Minimum değişiklik:** Public `unit_label` aynı sayfada tek ayrı literal text owner'a bağlansın; element/tag unit ve literal exact eşleşsin, text geometry/font/color/fill açık olsun, binding/chain olmasın. Public synthetic numeric donor `ShowUnit=0`, bütün captions için exact empty NUL2 frame ve complete separately qualified identity-conversion baseline istesin. UnitSrcVar/UnitDisplayVar `None`, percent/custom operand'ları finite literal olsun; external address operands kapalı kalsın. Raw source/donor/candidate context'i aynen korunsun. Low-level primary `set_unit_caption` **RAW RECORD ONLY** kalsın ve public intent'te `NATIVE_OPERATION_INTENT` ile reddedilsin.
- **Test:** `test_unit_label_cross_page_duplicate_and_shared_owners_are_rejected`, `test_unit_label_requires_explicit_exact_nonempty_units_and_literal_text`, `test_explicit_unit_label_has_one_visual_owner_at_its_own_geometry_and_style`, `test_linked_units_native_transactions_both_numeric_kinds_and_envelopes`, `test_public_units_reject_unqualified_hidden_conversion_and_caption_context`, `test_explicit_unit_noop_cannot_bypass_unqualified_source_context`, `test_saved_numeric_unit_context_corruption_is_rejected_before_output`, `test_embedded_unit_caption_low_level_operation_is_not_public_ir_authority` ve `test_linked_unit_contract_over_actual_stdio_both_envelopes` ilgili yolları sınar. Negative senaryolarda apply/output yokluğu ve immutable source beklenir.
- **Rollback:** Unit mutation candidate'ını bırak; kaynak conversion/caption bytes'ını silme veya normalize ederek baseline'a uydurma. Ayrı unit compiler yolunu exact yeni calibration'a kadar kapalı tut; read-only inventory/preservation kalsın.
- **Genellenebilirlik sınırı:** Baseline ve helper kendi exact source-local contract'idir; UnitDirection/font/enum/glyph/pixel veya full selected-model unit compiler kabulü değildir. 30 gerçek read-only History/SCAlarm unit-owner holdout'u yalnız framing/preservation gözlemidir; production/vendor/panel veya public Alarm IR/view/history desteğini açmaz. Mevcut examples değişmemiştir.

## U1 — Önemli: HTML-normalized ID fit kontrolünü atlatabilir

- **Gözlem / kanıt:** Reviewer CRLF/NUL içeren exact unit-label ID'siyle overflow kontrolünün string ID membership'ini atladığını buldu. `test_unit_label_fit_uses_stable_indexes_when_html_normalizes_identifier_controls` iki control-character biçimini generated HTML/data contract'inde sınar; `test_linked_unit_label_dom_fit_reports_overflow_without_changing_declared_font` font/overflow davranışını sınar.
- **Kök neden / etki:** JSON'daki ID ile HTML `data-element-id` normalizasyonu aynı değildir. String identity'ye bağlanan DOM fit/invalid-owner kontrolü literal label'ı tanımayabilir; deklarasyon fontunda sığmayan yazı hata vermeden kırpılabilir.
- **Karşı görüş / minimum değişiklik:** Exact IR ID validation/relation semantics'i değişmez. DOM'daki fit ve invalid-unit-owner membership için stable numeric element indexes kullan; label text'i design'dan tekrar yükle, glyph bounds'ını declared font ile ölç ve overflow bildir. Font küçültme. Bu test referansları browser-native rendering qualification veya yeni estetik kabulü değildir.
- **Negative regression:** CRLF/NUL içeren aynı-page ID ve 1×1 label geometry ile index membership'in korunmasını sınayın; overflow branch'i `INSUFFICIENT SPACE` üretmeli ve declared fontu değiştirmemelidir. Missing/invalid relation sample controls ile geçerli hale gelmemelidir.
- **Rollback:** Yeni preview candidate'ını bırak ve overflow kabulünü açık tut; ID'yi sessiz normalize etme veya text'i küçülterek onay üretme.
- **Genellenebilirlik sınırı:** Stable DOM index HTML identity translation riskini kapatır; native ID/UnitDirection/font/pixel qualification vermez. Conceptual renderer değiştiği için önceki renderer estetik kabulü yeni davranışa aktarılmaz.

## U2 — Önemli: semantic no-op caption length bytes'ını da korumalıdır

- **Gözlem / kanıt:** Reviewer primary caption literal'i değişmeden `UnitTextLen0=6`→`0006` length spelling değişikliğinin pure saved-candidate verifier'dan geçebildiğini buldu. `test_unit_semantic_noop_requires_exact_source_primary_record_bytes` iki envelope ve her iki spelling yönünde bunu sınar.
- **Kök neden / etki:** Caption-only companion signature primary record'u bilinçli olarak dışarıda bırakır. Yalnız decoded text eşitliğini denetlemek, semantic no-op'ta aynı literal'in raw framed record identity'sini korumaz; gereksiz serialization kaynak bytes'ını değiştirir.
- **Karşı görüş / minimum değişiklik:** Gerçek caption mutation length'i değiştirebilir. İstenen literal immutable primary text ile eşitse candidate primary `raw` record'u da kaynakla exact eşit olmalıdır; farklı length spelling `UNIT_CAPTION_MISMATCH` üretmelidir. Pure verifier candidate'ı onarmaz; complete companions/all secondary languages/context signature korunur.
- **Negative regression:** Aynı decoded `mm` için 6/0006 yazılışını değiştir; companion baseline eşit olsa da no-op verifier reddetmeli. Normal no-op apply tam source/envelope bytes'ını korumalıdır.
- **Rollback:** Candidate'ı bırak, caption mutation yolunu kapat; source length record'unu yeniden yazarak hatayı gizleme. Read-only decode/retention korunur.
- **Genellenebilirlik sınırı:** Raw no-op identity font/conversion/placement veya public unit caption mutation yetkisi değildir; helper RAW RECORD ONLY kalır.

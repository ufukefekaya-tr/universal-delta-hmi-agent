# Kaizen

Burada yalnız neutral, genellenebilir ders tutulur. Gözlem→kök neden→karşı görüş→minimum değişiklik→test→rollback→genellenebilirlik sınırı gerekir. Bir özel projenin etiketi/adresi/IP'si veya lisansı belirsiz fixture bu alana taşınmaz.

[Başlangıç dersleri](2026-10-11-neutral-lessons.md) tasarım/bağlama hatalarını önler; vendor/panel kabulü değildir. Bir ders core değişikliği gerektirirse exact scope/owner ve anlamlı regresyon kanıtıyla ayrı görev olur. Policy değişimini eski epoch altında üretme.

[Native donor sözleşmesi dersleri](2026-10-11-native-donor-contracts.md) explicit no-op, state/title, typed numeric storage, IEEE underflow ve opaque macro framing sınırlarını kaydeder. Test adları güncel kaynak regresyonlarına işaret eder; son revision/run kabulü root raporundan okunur.

[Macro/Alarm sözleşmesi dersleri](2026-10-11-macro-alarm-contracts.md) semantic no-op'ta tam record identity, known suffix ownership ve değişmeyen paired limit'in storage doğrulamasını kaydeder. Bounded writer ilerlemesi tam feature/vendor/panel kabulüne genişletilmez.

[Layout baseline ve guard dersleri](2026-10-11-layout-baseline-controls.md) S1–S7 page inheritance, appearance, Order, owner/mapping şekli, public IR intent ve exact navigation kind sınırlarını kaydeder. Negative regresyonlar, receipt-SHA corruption kontrolü ve rollback yolları belirtilir; önceki bounded reviewer/263-test Windows/ortam kabulü kendi tarihsel source revision'ına (tarihsel yerel kanıt; genel pakete dahil değil: `../reports/history/263/README.md`) bağlıdır ve unit kaynağına taşınmaz.

[Numeric unit ownership dersleri](UNIT_OWNERSHIP.md) double-unit/hidden conversion riskini, tek ayrı literal text owner'ı, inactive identity baseline'ını ve RAW RECORD ONLY helper sınırını kaydeder. U1 CRLF/NUL ID normalization bypass'ı, U2 semantic no-op length bytes'ı ve U3 unitless numeric'te yabancı Application/Screen owner'ı minimum scope/regresyon/rollback zincirleriyle tutulur. Exact yeni run/review/relocation kabulünü root ayrıca bağlar; full unit compiler/Alarm IR/view/history veya selected-model/vendor/pixel kabulü ilan edilmez.

[Native aday sınırları](NATIVE_CANDIDATE_BOUNDARIES.md) C1 post-link guard/owned-output rollback, C2 mutable projection/fresh decode bağı, C3 actual bounded read/stat yarışı, C4 typed profile JSON ve C5 actual SYNTHETIC/0.0 neutral approval sınırlarını kaydeder. Named regresyonlar source-pinned caption/geometri adayının dosya bütünlüğünü sınar; tam program writer, vendor veya panel kabulü değildir.

[Literal sayfa üretimi dersleri](LITERAL_PAGE_GENERATION.md) donor pin'inin feature calibration olmamasını, immutable donor çözümünü ve opak graph UNKNOWN iken dosya adayının vendor/execution kabulünden ayrılmasını kaydeder. Yeni header/text blokları için dar append deneyidir; full HMI program writer kabulü değildir.

[Ham/gösterim/keypad alanları](FIXED_DECIMAL_DOMAINS.md) exact ortak matematiği vendor binary dönüşümünden ayırır; source-qualified display kabulünü fractional input veya runtime kabulüne genişletmez.

# DIAScreen — yeni adresli maintained buton

Bu ayrı dosya yolu ortak `button / maintained` tanımından yeni native buton ekler. Kaynak 0/1 komut bitinin aynı BOOL adresini okur ve yazar. Yeni adres, kullanılmayan veya yalnız bu butona ayrılmış bellek anlamına gelmez. İstek durumu fiziksel çalışma geri bildirimi değildir.

İlk sözleşme model268502784 / serialized6.0.00209.8338 / 800×480 kaynak varyantındadır. Seçilmiş110IS veya bütün DOP-100 ailesi kabulü değildir. Eski shared-address clone ve B v1/v2 yolları ayrı kalır.

## Kaynak ve geçiş

Tam source SHA, 22 bölümlü prefix (WEB_OUTPUT dâhil), bütün page header/aux/owner sırası, resource tail, driver span, source namespace ve ayrı review artifact bağlanır. Private namespace aynı kaynak byte'larından kurulur; başka oturumun namespace nesnesi alınmaz.

Temperature kaynağı2/14 donor'u Type1/Sub4, direct Read/WriteMemType0/link2, BOOL0/2, Style2, canonical boş macro ve bağımlılıksız alanlar taşır. Aynı kaynak2/2 maintained nesnesi aynı storage/action alanlarında M100 scalar kullanır. Bu çift, yeni M scalar adresinin aynı doğrudan slotlara yazılması için stored native kanıttır. Kaynağın2/14 adresi D2005.0 olarak korunur ve yeni scalar grammar'a eklenmez.

Yalnız yeni nPartsID, X/Y/Width/Height, ReadVar/WriteVar ve primary State0/1 UTF-16 caption değişir. Read/Write adresleri aynı canonical BOOL M adresi olmalıdır. Type/SubType, storage, link, ReadMemType, WriteReadImmediately ve bütün başka alanlar değişmez. Native legacy font-name10byte record aynen korunur; decode/normalization yapılmaz. İki state fill değeri kaynak COLORREF metadata'sını taşır. Glyph, gradient, font veya native piksel kabulü çıkartılmaz; önizleme kavramsaldır ve kaynak native görünümü UNKNOWN'dır.

Momentary/set-on/set-off, sayısal nesne, bağımsız feedback tagı, yeni style/font/color, picture/macro/visibility/interlock/offset/group/unit/trigger verisi bu yolda reddedilir. FontName için yalnız bilinen narrow Arial veya pinned legacy record kabul edilir; bilinmeyen opaque donor alanı taşınmaz. Diğer source nesneler/global macro/resources byte-exact korunur. Initial/Open/Cycle macro'ları aktif kalır: bu temiz veya bağımsız sıfırdan program üretimi değildir.

## Portable MCP workflow

`scripts/calibrate_diascreen_buttons.py` kaynak, raw namespace sözleşmesi, portable registry authority ID, donor/target kimlikleri ve ayrı inceleme kaydını alır. Workspace-relative calibration/profile/design ve output/profiles/driver_contracts içinde byte-exact adres tablosunu üretir; native aday üretmez. Varsayılan okuyucu repo registry'sidir; MCP üretilen output/profiles registry'siyle açılır. Elle authority kopyalamak veya runtime'da repo dışına fallback yapmak gerekmez. Var olan exact authority yeniden yazılmadan kullanılır; farklı veri veya link reddedilir. Sonraki her metadata yayınında kaynaklar ve yeni authority yolu/hash'i yeniden kontrol edilir. Source/ref/review metadata'sı tek başına gerçek inceleme veya machine write authority kanıtı değildir.

Üretilen tasarım bütün eski owner'ları `native_preserved` olarak taşır. Kullanıcı/ajan standart `tags` ve `button` ekler: behavior maintained, role request, read/write aynı tag, açık0/1 metinleri. Tag, BOOL/ReadWrite/channel/station/native link+mem_type alanlarını açıkça taşır. Ekstra veya kullanılmayan niyet sessizce atılmaz.

Dokuz araçlık file MCP'de open/inspect → plan → conceptual preview → validate → exact approval → apply → new-only save/reopen → diff akışı izlenir. Source/profile/calibration/review/registry raw hash'leri işlem ve kayıt öncesi yeniden kontrol edilir. Tasarım veya binding değişince eski onay geçmez. Aynı kaydı tekrarlamak aynı byte'ları döndürür; var olan başka dosyanın üzerine yazılmaz.

Native setter emitter, orijinal raw record splice oracle'ıyla whole BODY düzeyinde karşılaştırılır. Kaydedilmiş aday tekrar parse edilir; yalnız yeni owner extent'lerini çıkarmak orijinal BODY'yi tamamen geri getirmelidir. Thumbnail, tail ve eski kayıtlar korunur; gerekli BODY length alanı kontrollü düzeltilir. Türkçe UTF-16 metin saklama font glyph kabulü değildir.

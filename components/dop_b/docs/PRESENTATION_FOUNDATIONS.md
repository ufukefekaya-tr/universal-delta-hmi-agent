# Mevcut görünüm ve arka plan temelleri

[Mevcut giriş izni](EXISTING_ENTRY_PERMISSION.md) ayrı source/namespace/action descriptor ile yalnız explicit START SetOn ve F0 parameter girişinin saklanan InterLockVar/Level kayıtlarını düzenler. Link ve original write binding korunur; numeric original-disabled guard açılmaz. Bu özellik kalite/maximum-age/AND, continuous/commit-time/safety, vendor/runtime/native piksel veya tam batch kabulü değildir. Güncel kabul [doğrulama raporundadır](../reports/VERIFICATION.md).

Yeni [mevcut WORD numeric yolu](EXISTING_INTEGER_NUMERIC.md), immutable storage/adres ve kaynakF0 input sınırlarıyla ayrı public descriptor taşır. Bu temellerin eski kabulü yeni numeric özelliğin testi yerine kullanılmaz; fractional keypad input halen kapalıdır.

Bu iki pure-byte temel699testli [tarihsel kabulde](../reports/PRESENTATION_FOUNDATIONS_MILESTONE.json) bağımsız doğrulandı. Sonraki [existing_edit public birleşimi](EXISTING_EDIT.md)751root/independent testle ayrı kabul edildi. Temel kanıtı native pixel/runtime veya tam batch kabulü değildir; [güncel rapor](../reports/VERIFICATION.md) iki scope’u ayırır.

`ExistingPresentation(source, existing_graph_schema, descriptor)` kaynak model/sürüm/SHA’sını ve kapalı native graph’ı doğrular. `set_existing_presentation` yalnız mevcut nesnenin tam geometri, native_style ve pinli durumlara ait font/metin/yüzey renklerini değiştirebilir. Orijinal scalar kayıtlarının gerçek uzunluğu değişebilir; metin, adres, numeric limit/format, komut davranışı, macro, gezinme ve kaynak kaynakları byte eşit korunur. No-op bütün dosyayı eşit bırakır. Başka kind, görünmeyen renk rolü, duplicate veya stale pin açık hatadır. Beklenen gövde emitter’dan bağımsız kaynak kayıt aralıklarıyla kurulur; ters yerine koyma orijinal gövdeyi geri getirmelidir.

Yeni FontSize değerleri yalnız 8,10,12,14,16,18,20,22,24,28,32,36,40,48,64,72; FontRatio yalnız 33,50,100,150,200. Vendor okuyucusu diğer ratio’ları 100’e, diğer size değerlerini tabloya dönüştürdüğü için bunlar üretilmez. Kaynakta bulunan 0/48 değiştirilmeden korunabilir; bunun runtime’da eşdeğer olduğu iddia edilmez. Button/indicator yüzeyi FgColor, numeric yüzeyi BgColor’dır. Numeric border yalnız sonuç style0’da değişebilir. Native style3 text-only’dir; runtime16 değeri dosyaya yazılmaz. COLORS COLORREF24’tür; font/glyph/native piksel kabulü değildir.

`decode_opaque_png` ve `frame_pixels_from_png` yalnız RGB8 veya tüm alpha baytları255 olan RGBA8, noninterlaced PNG kabul eder. IHDR/consecutive IDAT/terminal IEND, CRC, beş filtre ve tek bounded zlib stream doğrulanır. Palette, color profile, animation, transparency, extra chunk/trailer ve boyut uyumsuzluğu reddedilir. Hedef mevcut40-byte BI_RGB32 pozitif-height DIB olmalıdır; header/same-size/bottom-up BGR ve reserved X=FF korunur. X byte alpha sayılmaz. Resize/crop/renk düzeltme yapılmaz.

PNG primitive tek başına hangi sayfanın hangi kaynağı kullandığını doğrulamaz. Registered authority, gerçek Background frame extent/PictureOffset sahipliği, workspace-relative asset SHA/freshness, bütün gövde birleşimi ve public dokuz-tool saved/replay akışı sonraki existing_edit milestone’unda ayrıca uygulanıp sınandı. Arka plan selected-page editor tüketim zinciri yalnız static araştırmadır; gerçek vendor derleme veya çizilmiş native piksel testi yapılmadı.

Signed F1/F4 limit araştırması [ayrı koşullu kayıttadır](../reports/NUMERIC_LIMIT_RESEARCH_UPDATE.json). Doğru decimal gösterim, tuş takımı girişinin integer normalizasyonu ve compiler limit dönüşümü farklı kabullerdir. Actual CRT/thread/locale ve pipeline kanıtı bulunmadan bu araştırma public giriş capability’si açmaz. Var-address limitlerde stale/reversal bulgusu devam eder.

Bu modüller çekirdekte sabit müşteri yolu, görseli veya tag’ı taşımaz. Gerçek kaynakta yapılan ek görünüm deneyi yalnız bellekte kaldı; başka projenin dosyası değiştirilmedi. Public existing_edit birleşimi ayrı offline scope’ta kabul edildi. Signed numeric/quality/interlock, iki gerçek profile, vendor/panel ve tam V1 açık kalır.

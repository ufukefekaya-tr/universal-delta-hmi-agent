# Mimari ve public API

V1 özgün Python dosya mühendisliği çekirdeğidir. Python 3.14 isolated venv ve MCP SDK 2.3.0 ile gerçek stdio entegrasyonu uygulanmıştır; initialize, dokuz tool listesi ve tool çağrıları test edilmiştir. Test revision ve son teslim kabulü [VERIFICATION](../reports/VERIFICATION.md) kaydındadır. Lisansı belirsiz üçüncü taraf uygulama kodu vendoring yapılmaz.

Runtime bağımsız Git repo'suyla başka host'a taşınır; Git ve Python 3.14+ gerekir. `.venv` ve eski client config taşınmaz; lock + pinned setuptools ile yeni editable install yapılır. Registry/workspace varsayılanları checkout konumundan çözülür; client cwd'sine veya yazar PC yoluna bağlı değildir. Genel başlatma `python -m universal_hmi.cli serve`; `configure_mcp.py` yalnız yeni host'a ait stdout config üretir. [Taşınabilirlik](PORTABILITY.md) temiz ortam/OS kabul sınırını açıklar; Linux runtime NOT_RUN'dır.

Mevcut uygulama shared IR, validator/conceptual renderer, lossless codec/records ve kaynak içindeki exact donor üzerinden kısmi native derleyicidir; tam IR→native compiler değildir. Genel özgün synthetic yolda `plan_changes` operations atlandığında veya `null` olduğunda button/numeric, exact text/indicator/goto donor'ları, boş inert page clone, rename/bounded section order, linked numeric unit text owner ve qualified source-local bounded macro yamaları derlenir. Mevcut active-high BOOL Alarm kayıtlarının yalnız primary mesajı ve sunumu aynen korunan current/history/strip owner'larının geometri/klon subset'i de bu bounded yoldadır. Gömülü native unit caption helper'ı public compiler değildir. Önceki layout ve [unit milestone](../reports/NATIVE_UNIT_MILESTONE.json)/[review](../reports/NATIVE_UNIT_REVIEW.md) kabulleri kendi source/test revision'larına aittir; exact yeni frozen suite/review/relocation kabulü [güncel raporda](../reports/VERIFICATION.md) ayrıca bağlanır.

Kalibrasyonsuz gerçek profiller için `PRODUCTION_EMISSION_PENDING` sürer; `qualified: true` veya yalnız insan onayı full compiler kapısını açmaz. Ayrı **kaynağa bağlı existing-owner aday yolu**, gerçek B/DIA kaynağındaki seçilmiş mevcut sabit text başlık/geometrisini aynı byte extent'inde değiştirip diğer içeriği koruyabilir. Bu istisna source/schema/calibration witness'i, raw owner hash'leri, tam beklenen decoded byte karşılaştırması ve exact insan onayı ister; `program_writer_complete=false` kalır. Tam selected-model unit/caption compiler, native font units/picture/gradient/transparency, `Order` ile layer semantiği, geniş macro/driver ve temel alarm/history davranış qualification'ı açıktır. G2/G3 alarm history kapsamı `[Alarm]` yapılandırması ve Type=11/SubType=1 nesnesidir; `[History]` process sampling V1 baseline dışındadır.

```text
MCP stdio / CLI
    → service (session, immutable source SHA, plan/apply contract)
        → shared model + validation + conceptual preview
        → format/profile dispatch
            → DOPSoft 2 / .dps native adapter
            → DIAScreen / .dpa native adapter
        → qualified schema + feature/scenario evidence gates
    → SYNTHETIC/0.0 source-local object/layout + linked-unit text owner + bounded internal macro patches
        + existing BOOL primary Alarm messages + source-preserved Type11 views
        → save_as → reopen + inspect + diff
    → low-level embedded unit caption helper (RAW RECORD ONLY; public use CLOSED)
    → low-level qualified global Alarm records (broader mutation is not public authority)
    → source-pinned existing-owner text/geometry candidate
        → source/schema/calibration witness + direct human approval
        → raw retained layout + complete decoded-byte target → new save_as
    → full real native program writer: NOT COMPLETE (development + qualification pending)
```

Çekirdeğin vendor GUI, socket/PLC bağlantısı veya upload/download modülü yoktur. İnsan IDE/panel kanıtı dosya hash'ine bağlı dış kanıttır. Native adapter'ı doğrudan çağırmak service onay gate'ini atlamaya yetki vermez.

Yalnız dört kaynak kontrolünün fresh ID/geometri/primary0/1 yazıları değişir; bütün stored type/binding/storage/limit/style/efekt/makrolar korunur. Kaynak owner hash'leri yeni parse üzerinden `(page,id)` anahtarıyla, bütün Element+States byte'larından tek geçişte hesaplanır; kalıcı hash cache'i kullanılmaz. [Ayrı sözleşme](DIASCREEN_CONTROL_APPEND.md), genel control/program/runtime kabulü değildir.

## Kaynağa bağlı existing-owner aday yolu

`scripts/calibrate_source.py` yeni native dosya üretmeden üç proje-local JSON sözleşmesi oluşturur: source/owner witness'i `CALIBRATION.json`, ayrı registry'deki `existing_owner_v1` profili ve bütün owner'ları `native_preserved` temsil eden design. Gerçek B veya DIA family marker'ı, kaynak SHA/model/raw sürüm/çözünürlük, schema SHA, provenance/review referansları ve editable owner SHA'ları birlikte doğrulanır. Komut, yeni MCP registry başlatma ve fresh-agent adımları [aday kılavuzunda](NATIVE_CANDIDATES.md) ve [DOP-B başlangıç talimatında](../prompts/DOP_B_PROGRAMMER.md) bulunur.

Yalnız önceden seçilmiş `Type=10/SubType=6`, tek açık `State.Value=0`, inert Read/Write/offset/visibility ve executable macro içermeyen literal text owner'ı düzenlenebilir. Primary `wTextLen0` terminal NUL dahil UTF-16LE byte extent'i, X/Y/Width/Height scalar'larının ASCII extent'i değişmez. Text IR tam sekiz alanla sınırlıdır; style/state/binding/macro/alarm/goto intent'i yoktur. Diğer bütün owner'lar full Element+State SHA ve aynı kaynak geometrisiyle `native_preserved` kalır; clone/delete/edit yetkisi yoktur. Bütün sayfaların adı, boyutu, owner/State sırası, raw Order, globals, opaque tail ve envelope prefix/thumbnail korunur.

Pure final verifier beklenen payload'ı immutable kaynaktan ve yalnız onaylı IR text/geometrisinden türetir; candidate decoded bytes bütünüyle buna eşit olmalıdır. Semantic no-op bütün original container bytes'ını korur; değişmiş container sıkıştırma byte'ları yeniden oluşabilir. Byte extent'ini korumak yapısal yer değiştirmeyi sınırlar; retained opak metadata'nın offset, thumbnail veya vendor davranış semantiğini çözmüş sayılmaz.

Bu branch'te mevcut Type11 dahil desteklenmeyen nesneler bütün halde `native_preserved` olarak tutulabilir; her Type11 için declared `alarm_view` üretmek gerekmez. Koruma alarm/widget/lifecycle desteği vermez; bu nesnelerin metadata, geometry, macro veya bağımlılığı değiştirilmez. Generic Alarm view compiler'ın foreign-owner/behavior kısıtları bu retention yoluyla mutation yetkisine dönüştürülemez.

Preview `CONCEPTUAL_IR / TEXT INTENT ONLY`'dır: metin ve koordinat niyetini gösterir, retained native font/style/glyph/pixels'i çizmez. Unknown owner açık `SOURCE OBJECT / NATIVE NOT RENDERED` placeholder'ıdır. Direct human approval source/profile/design/bindings/operations/**calibration** SHA'larına bağlıdır. Approval etiketi veya `qualified` flag tek başına yeterli değildir. `OFFLINE_NATIVE_CANDIDATE` amaçlı yeni dosya kaydedilebilir; `production_native=UNAVAILABLE`, `program_writer_complete=false`, native visual/vendor/physical `NOT_RUN` kalır. Default gerçek hedef profilleri `UNVERIFIED` olarak korunur.

## Kısmi native derleme sınırı

Bu bölümün donor/clone/style/Alarm davranışları genel bounded synthetic derleme yolunundur. Source-pinned existing-owner adayında bunların mutation yetkisi açılmaz; aşağıdaki ayrı retention sözleşmesi uygulanır.

Otomatik yol bütün mevcut native sayfaları exact ID ile tasarımda bir kez ister; sayfa silme kalibre değildir. Sayfa boyutları kaynakla eşleşir. Yeni sayfa, profile'daki exact source-local `screen_donor` ile clone edilir: donor nesnesiz, executable macro bytes ve schedule taşımayan inert sayfa olmalıdır. Yeni nesne immutable kaynaktaki exact screen/element donor ID'sini ister. Bütün sayfa/nesne donor'ları kaynak üzerindeki yama veya silmeden önce clone edilir; global yol veya dış şablon kullanılmaz. Qualified rename/reorder ile tasarımın adı ve tam section sırası uygulanabilir; bu gerçek z-order/pixel görünümü kanıtı değildir.

Yeni page donor için `page_baseline(screen_id)` yalnız yedi Screen alanını kabul eder: VER=16, ID, wTextLen, DocSizeX/Y, PanelSizeX/Y. Extra/duplicate/unkeyed kayıt, background/BaseScreenID/lock/page-macro gibi inherited alan qualified değildir. ID canonical nonnegative, boyutlar canonical positive ve en çok 2147483647; name tam UTF-16 frame ister (empty terminal-NUL name olabilir, absent frame olamaz). Immediate empty AuxKeyElement ve complete known owner extents zorunludur. SHA, Screen.header + sıralı raw ID/name dışı kayıtlar + Aux.header'dan hesaplanır; ID/name ve defined object bytes dışarıdadır, object extent denetimi devam eder. Bu signature nonempty source donor'a izin vermez. Saved yeni page baseline'ı immutable donor ile aynı olmalıdır; bütün mevcut sayfaları yedi-field-only sayma.

Button/numeric yanında text/indicator/goto için de exact qualified native kind ve source-local donor gerekir. Geometri, language-0 yazıları, explicit state value/text/24-bit fill ve typed read/write bindings yamalanabilir. Native caption, boş yazı dahil, intent'te açık verilmelidir; donor yazısı sessizce devralınmaz. Numeric donor'daki bildirilmeyen State caption reddedilir; State text metadata'sı Element-owned `UnitTextLenN` caption'ından ayrıdır. Linked unit ayrı ordinary text donor'u kullanır. State değeri section pozisyonundan türetilmez; indicator request ile fiziksel feedback'i birleştirmez. Sayfa adı/sırası, state kümesi, binding ve momentary sabit başlığı saved-file contract'inde denetlenir; explicit operations bunları atlamaz. Önceki layout service verifier/bağımsız review kendi bounded revision'ında OFFLINE_PASS'tır; desteklenmeyen field veya kind açık hata verir.

Alt seviyedeki yapısal operation'lar dokuz public MCP tool'a ek tool değildir:

| Operation | Exact parametreler | Qualification sınırı |
|---|---|---|
| `rename_screen` | `screen_id`, `name` | `native_schema.structure.qualified` ve `wTextLen` mapping; bütün bilinen navigation ID/name companions birlikte güncellenir. Unknown ScreenID/ScreenName benzeri reference, stale companion veya kalibre edilmeyen name encoding reddedilir. |
| `reorder_elements` | `screen_id`, `element_ids` | Tam, tekrarsız mevcut-ID permutation; `section-sequence` / `element-and-states` mapping. Element+State owner blokları korunur; sayfa/nesne/state içinde `Order` varsa layer ilişkisi kalibre edilmediği için reddedilir. |
| `reorder_screens` | `screen_ids` | Tam mevcut-ID permutation; `section-sequence` / `screen-and-elements` mapping. Application-only prefix ve bütün page/object blokları korunur; Screen `Order` reddedilir. Sayfa içindeki katman anlamı değişmez veya qualified sayılmaz. |

Varsayılan public otomatik preflight ve final guard `verify_layout_order()` ile bütün sayfalarda immediate empty Aux/full extents/Application-only prefix ister. Screen/Element/State içindeki herhangi bir `Order`, değeri 0 olsa da, bu genel yolda no-op ve append-only planda da reddedilir. Ayrı `preserved_layout` existing-owner sözleşmesi raw source SHA, prefix/section SHA'ları, sayfa kayıtları, owner/State sırası, bütün raw Order kayıtları, envelope prefix/thumbnail ve tail'i aynen koruyarak mevcut Order'ı kabul edebilir. Bu bir z-order çözümü veya section reorder yetkisi değildir. Tek low-level operation'ın kontrolü public final guard'ın yerine geçmez.

Extent/boundary guard'ları no-op'ta da çalışır; yalnız kalibre edilmiş boş leading AuxKeyElement marker kabul edilir. Exact no-op kaynak bytes'ını korur. Ordinary `font_size` yalnız **State.FontSize0** alanına, explicit scale=1, bütün state'lerde FontRatio0=100 ve açık ASCII FontName0 ile yazılır; Element.FontSize desteklenmez. Bu scalar eşitliği points/pixels veya native glyph boyutu eşitliği değildir. `color`→FontColor ve `fill`→BgColor için qualified exact field/scope/range ve element/state companion baseline gerekir. Encoding açık seçilir: özgün synthetic fixture için `rgb24`, separately calibrated contract için `colorref24` (`R | G<<8 | B<<16`); byte/channel düzeni tahmin edilmez. Kaydedilmiş vendor thumbnail COLORREF için yalnız corroboration'dır, candidate native visual kabulü değildir.

Appearance guard Font/Picture/PIB/opacity/shadow/gradient gibi isimleri yalnız başta değil field adının içinde de arar: NumBgOpacity, BtnPictureStretch/CtrPicture*, FieldFontSize/ScaleFont*, Range/TargetOpacity kind-prefix'iyle saklanmaz. Show/Trans/Fill/FgFill*/Grad/AutoResize/UseBMPText/SmoothFont ve diğer appearance companions owner scope/raw baseline ile açıklanmalıdır. Bilinmeyen visual mapping key editable muafiyeti oluşturamaz. PictureOffset, `PIB Name` veya `Picture Name`, UsePictureCoord=0 olsa da flat-style yolunda reddedilir. State-only fill de aynı appearance guard'ından geçer; checked-in profillerin empty-companion contract'i yalnız özgün synthetic fixture içindir. Önceki layout revision'ındaki S1–S7 düzeltmeleri [review](../reports/NATIVE_LAYOUT_REVIEW.md) ile kapanmış ve kendi Windows fresh clone/ortam/manifest/scoped commit kabulüne bağlanmıştır; bu tarihsel kabul unit revision'ına aktarılmaz. Vendor flat-style/native font units/glyph/picture/gradient/transparency/layer/pixel kabulü oluşturulmaz.

`configure_numeric` yalnız separately qualified numeric mapping ve exact donor kind/type ile çalışır. `MemLen`/`MemFmt` storage önkoşuldur ve değiştirilmez; width/enum uyuşmazlığı no-op'ta da hatadır. Mevcut synthetic profiller INT/UINT/DINT/UDINT/REAL mapping'lerini tanımlar; bu gerçek hedef qualification'ı veya tüm 64-bit/TIME desteği değildir. Input raw minimum/maximum ve digit sayıları açıktır; display operation input limit alanı icat etmez. Gain=1/offset=0 dışında scaling kalibre değildir. Bounded exact Decimal limitleri korunur; IEEE width overflow veya sıfır olmayan limitin sıfıra underflow olması reddedilir, temsil edilebilir subnormal ayrı test edilir. Fractional digit sayısı PLC scaling'e dönüştürülmez.

`configure_goto`, qualified navigation mapping, aynı Type/SubType donor davranışı ve candidate içindeki exact hedef sayfa ister. Public automatic preflight ve final/no-op verifier, kind'in tam canonical Type+SubType setini ve navigation.match eşitliğini ister; Type-only mapping yanlış subtype'ı gizleyemez. Varsa GoToScreenName actual target adına bağlı ve explicit name_encoding: ascii olmalıdır; ID-only donor'a name record icat edilmez. Host codepage fallback veya Unicode narrow-name tahmini yoktur. Real selected-profile qualification açık kalır. Model ID signed decimal/eşdeğer uint32 kimliğini tanır; raw model bytes'ı yeniden yazmaz ve family/editor denetimini kaldırmaz.

## Numeric unit compiler subset

Public numeric `unit_label`, aynı sayfada exact ID ile tek bir ayrı literal `text` owner'a bağlıdır. Element `unit`, bound tag `unit` ve owner `text` açık ve exact eşittir; text owner kendi geometry/font/color/fill alanlarını taşır, binding veya reference chain taşımaz. Input read/write aynı process tag'i ve unit'i temsil eder. Shared validation ve conceptual preview sözleşmesi [DESIGN](DESIGN.md#sayısal-birimin-tek-yazı-sahibi) içindedir. Public compiler ordinary text donor'unu ve qualified text/style mapping'ini kullanır; numeric birim veya caption'ın yerini native `UnitDirection` değerinden üretmez.

Linked numeric native donor'un embedded unit'i inactive olmalıdır: `ShowUnit=0`; primary dahil **bütün** `UnitTextLenN` caption'ları exact empty UTF-16LE terminal-NUL frame (2 byte) olmalıdır. Zero-length frame bu koşulu karşılamaz. `native_schema.unit_context` ayrı olarak `qualified: true`, `owner: Element`, `value_model: identity` ve complete exact string-value `fields` baseline ister. Baseline bütün 22 primary companion'ı ve varsa tam secondary-language `UnitTextLenN/UnitFontSizeN/UnitFontNameN` üçlülerini kapsar. `UnitSrcVar`/`UnitDisplayVar` yalnız exact `None`; percent/custom operands yalnız açık finite numeric literal olabilir, external address operand'ları kabul edilmez. Hidden caption, unknown/duplicate/alias unit field veya State-owned unit metadata qualified değildir. Bu contract'in varlığı enum anlamını tahmin etmez; identity model'i her exact donor/profile için ayrıca kanıtlanmalıdır.

Kaynakta unit metadata varsa numeric design birim belirtmese de context denetlenir. Her numeric emission için Application/Screen unit metadata'sı immutable source/donor page ve saved candidate'da unconditional reddedilir; State-owned unit metadata da unqualified'dır. Unitless numeric IR bu owner gate'ini kapatmaz; raw read-only parsing/preservation ayrı kalır. Immutable source/donor ve saved candidate `unit_context_baseline()` raw signature'ları exact eşleşir; caption, conversion, direction, bütün secondary languages veya başka unit companion'ın değiştirilmesi/çıkarılması no-op'ta da reddedilir. Clone numeric context'i immutable donor'dan alır; text owner ayrıca clone/emit edilir. Automatic, explicit/no-op, apply ve new-only save_as kapıları aynı represented intent/context sınırını korur. Synthetic test profilleri bu ayrı baseline'ı test içinde kurar; checked-in registry'ye selected-model qualification eklenmez.

### Embedded caption helper — RAW RECORD ONLY

Native parser exact `UnitTextLenN` record'larını Element-owned UTF-16LE byte-length/NUL frame olarak decode eder; ordinary State caption inventory'sinden ayrı `unit_captions` bildirir ve qualification'ı `UNVERIFIED` tutar. Benzer isimli key'den frame tahmini yapılmaz. Low-level `set_unit_caption(screen_id, element_id, text, expected_unit_baseline_sha256)` yalnız separately qualified exact numeric kind/Element/`UnitTextLen0` mapping, complete owner extent, enabled `ShowUnit=1` ve mevcut NUL frame ile primary literal'i değiştirir. Bu **RAW RECORD ONLY** contract unit conversion/placement/font/native görünüm compiler'ı değildir ve public `plan_changes`/`apply_plan` intent'inde `NATIVE_OPERATION_INTENT` ile kapalıdır.

Tam primary companion kümesi `UnitType`, `UnitSrc`, `UnitSrcVar`, `UnitDisplay`, `UnitDisplayVar`, `UnitPercent`, `UnitPercent1Var`, `UnitPercent2Var`, `UnitCustom1Var_1`, `UnitCustom2Var_1`, `BackupUnitSrc`, `BackupUnitDisplay`, `ConvertConstByUnit`, `ShowUnit`, `UnitDirection`, `UnitFontSize0`, `UnitFontName0`, `UnitTextLen0`, `UnitBold`, `UnitItalic`, `UnitUnderline`, `UnitFontColor`'dır. Caption-only baseline Type/SubType ve primary caption dışındaki bütün unit-related raw records'ın sıralı signature'ını tutar; secondary captions/languages ve unknown unit extensions korunur. Context signature primary caption dahil bütününü tutar. Semantic no-op primary record'un tam raw bytes'ını, length-field yazılışı (`6`/`0006` gibi) dahil korur; eşit decoded literal length normalization'a izin vermez. Disabled/zero-length donor read-only retention'ı mutation yetkisi değildir.

Özgün synthetic unit/design/native/service/stdio regresyonları bounded development contract'ini sınar; run/revision kabulünü root [unit milestone](../reports/NATIVE_UNIT_MILESTONE.json)/[review](../reports/NATIVE_UNIT_REVIEW.md) raporlarına bağlar. 30 gerçek read-only History/SCAlarm unit-owner holdout'u framing/raw preservation gözlemidir; private kaynak/asset paylaşılmaz. Bu kayıtlar selected-model fixture, üretim emitter, vendor font/enum/`UnitDirection`/pixel, full unit compiler veya yeni public Alarm subset'inin kabulünü açmaz. Tam V1 G2/G3 ve gerçek profile/pilot/vendor/panel kapıları açık kalır.

## Bounded macro ve Alarm

`MacroProgram` lossless REV frame'i korur; `configure_macro` yalnız immutable source-local owner/program/line SHA, descriptor ve bütün flag byte'ları pinli donor'larla semantik yazar. Public IR subset'i internal UINT/UDINT/DINT integer-literal assignment, BOOL bit_on/bit_off ve UINT `eq` IF/then/else'dir. Internal address span ve typed binding profilde açık olmalıdır. Alt seviyedeki integer `add` literal/direct-internal operands desteği public IR desteğine genişletilmez. External/DIA_TAG adresleri, alias, REAL/TIME, diğer karşılaştırmalar ve kalibre edilmeyen komutlar fail closed'dur.

Public startup→application InitialMacroLen, clock→application ClockMacroLen ve button→exact retained button/execution-field eşlemesi macro ID başına profilde açıkça verilir. Clock delay/priority dahil mevcut raw schedule bütünüyle aynı kalır; period/unit/default veya owner tahmin edilmez. Profile hash onaya bağlıdır. Saved candidate declared intent'i, unmanaged owner/program'ları ve schedule'ı yeniden doğrular.

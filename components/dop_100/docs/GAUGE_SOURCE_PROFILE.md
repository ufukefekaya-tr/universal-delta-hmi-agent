# Gauge readback and fresh source profiles —0.3.1 / DIAScreen0.4.2

A literal `ScaleFontSize` on source-observed Type3/SubType1, DOP-107EV/native6.6.2.48 is indexed without treating the point size as an unknown byte frame. Other model/version/family/unknown-frame variants remain closed. Native source opening and project views reject incomplete indexes rather than reporting a partial page count as a complete project.

`intake_source_profile(path,source_sha256,expected_link,expected_station)` is a read-only profile proposal before opening. It verifies the actual native link/station, complete index and known counted tail grammar through END. Three observed Alarm/NewTextBank font fields are scalar; unknown resource fields/opaque variants still fail. No header searching or old offset remapping is used. Historical acceptance metadata is not copied. The returned profile/hash is source framing evidence, not vendor, PLC, account or runtime acceptance.

In the gateway this tool is stateless; only those four arguments are forwarded into the existing trusted backend. It does not register a profile or widen the pinned host registry. Opening still requires a host-approved `profile_id`. The direct backend uses the returned exact profile/hash after caller inspection.

Existing Type12/3 system/login controls support source-retained copy/replacement/move/geometry/text. Action/Level/credential owners remain unchanged. Empty macros may use `retain_macros=False`; nonempty macros require explicit retention. This is not an account/password constructor.

Atomic `delete_element` supports only macro-free readonly indicators/static labels. Group, event, file-browser and unknown/incoming PartID dependencies are refused. New gauge enum/binding writers, direct visibility enum writers and native account/recipe/history constructors are not added. Exact known donors can retain existing numeric/visibility behavior without inventing enums.

The general backend exposes70tools; the separate project deployment has83 including its local references/templates. No customer DPA, source profile, tags, endpoint, credentials, fonts or machine generators are in this source patch. Existing offline bundles remain immutable; this is a source update. User-edited source is always an immutable staged snapshot for candidate work; live originals are never overwritten.

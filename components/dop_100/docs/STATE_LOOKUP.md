# Source-qualified state text lookup —0.3.2 / DIAScreen0.4.3

`plan_native_update` accepts `op="state_lookup"` for a complete 1..128-value text lookup derived from an immutable source Type7/SubType1 template. Donor descriptor fields are `path`, `source_sha256`, `page_id`, `element_id`, `element_sha256`, and `template_state_value`. Keep the donor in the same workspace using a normalized relative path. The actual file is held, hashed and parsed during planning and again during reconstruction/apply/save. A changed, missing or linked donor is refused.

The operation replaces an explicitly hashed macro-free readonly source owner. Its identity and rectangle are retained unless explicit bounded geometry is supplied. Application, credentials, global macros, unowned objects and resource banks remain exact. Native source/donor model and version must match. Donor headers and all source states use a closed observed plain-text schema. Group, picture, event, indirect fill, unknown and visibility dependencies are refused. Font names must already exist in the destination and are retained.

The hash-bound typed contract must declare a readonly INT, one-word register and its complete nonnegative enum domain within0..32767. The explicit states must match that set exactly, including sparse sets. Each state supplies `value`, exactly three `texts`, three `sizes` within8..56, observed `alignment`/`bold`, and explicit `colors` with `font`/`background`/`foreground` RGB values. The binding supplies `address`, `type="INT"`, `access="READ_ONLY"`, `link` and `station`. Existing native MemLen1/MemFmt2 WORD representation is preserved: this is the separate `LOOKUP_WORD16_NONNEGATIVE` role, not a signed native type or general INT/WORD/BOOL coercion.

The returned profile pins each lookup owner hash and declared values. Native plan proof and `inspect_native_catalog` expose these records. `validate_bindings` verifies the dedicated role against the exact native owner and full enum set; the generic type validator continues to refuse Type7 as an ordinary INT widget. A later edit to that owner invalidates its lookup marker and requires requalification.

Use the ordinary inspect → hash-bound plan → exact digest approval → apply → new-only save → fresh reopen workflow. This does not introduce a new transport or bypass approval. Tool inventory remains70generic/83project-local. Unknown runtime values have no qualified fallback behavior. Text lookup is not a simultaneous DWORD mask decoder, alarm history, PLC diagnosis implementation or vendor/panel acceptance. Offline bundles remain historical; this is a source update.

## Original implementation boundary

Bounded container/resource parsing retains byte ownership and unknown spans. Symbol resolution follows actual types/member offsets, inclusive array bounds and intersected access; missing layout remains unknown. Macros use observed header/opcode/five counted byte fields/trailer and keep field0 separate. These facts do not grant a general source compiler, hidden record semantics or family-wide qualification.

Opaque prefixes, MeMeCode, SRAM, driver fields and unknown resources stay unchanged outside exact approved ledgers. Recompression equivalence is distinct from original compressed-file identity. Full decoded-payload/thumbnail inverse checks cannot prove vendor grammar or runtime behavior.

## Reproduction and claims

Public installation/tests require no private source. Optional private qualification needs separately supplied matching hashes and is not packaged. Earlier module runs and historical native checks are observations, not final release acceptance. Final root verification must publish actual test names, final code/package identity and independent review findings.

Compiled inspection verifies caller-linked artifact/source/candidate hashes and performs a conservative partial descriptor scan. It does not authenticate the caller receipt, prove which compiler ran, parse all CIN semantics or turn CompilePASS into runtime success.

Vendor compilation, native pixel fidelity, panel/runtime, physical feedback and machine safety remain outside offline acceptance. No editor automation, PLC connection, force/download or energizing belongs to extraction, reproduction or tests.

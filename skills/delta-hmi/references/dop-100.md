# DOP-100 / DIAScreen file workflow

`dop_100__open_project(profile_id, path, source_sha256)` selects a trusted host
profile and returns a new isolated `session_id`. The gateway injects profile
JSON; do not supply or invent it in tool arguments. Pass this session to project
calls and close it with `dop_100__close_session`. Use actual saved native framing
and target readback, not the `.dpa` suffix, as format evidence.

Inspect the exact source before `plan_changes` or `plan_native_update`. Native
transactions require source owner hashes and a specification digest. Read a
proposal with `inspect_native_plan`, preview and validate it, then use authorized
`apply_plan(plan_sha256, approval_sha256)` with the same immutable digest.
`save_as`/`save_new` require the exact current candidate hash and a separate new
path. Reopen saved bytes and inspect layers, bindings and differences.
An unsupported preview layer must leave visual acceptance open; do not hide it
with a simplified redraw or promote a synthetic preview to vendor pixels.

`list_deliveries`, `current_delivery`, `inspect_parameters`,
`get_reference_contract` and `inspect_template` are stateless catalog reads.
Catalogs are host-owned, external and empty by default. `open_delivery` and
`create_project` create new isolated sessions. `create_project` is a durable
proposal to copy an exact qualified neutral seed; it does not invoke a vendor
constructor. Pin the seed/profile/catalog/engine from `inspect_template`, inspect
the proposal, then call authorized `apply_project_plan`. The byte-identical copy
opens as source in that session through the catalog-owned profile.

`configure_target` accepts only an unchanged registered blank and an explicit
blank-to-template relation, with a separate new output. It cannot convert a
machine project to another model. `inspect_target_configuration` separates
actual Application communication fields from declared metadata; absent or
mismatching fields are not a successful driver test.

`create_neutral_screen` derives a qualified stock frame with zero widgets,
changing only ID/name/title/background. `inspect_neutral_screens` checks complete
ancestry. Its 128-page bound does not raise ordinary transactions' 96-page bound.
Object moves/clones to a newly created page require a subsequent inspected
transaction. Navigation needs an actual source navigation control and the final
target page name; dormant donor fields are not live edges.

`colors.foreground` changes only `FgColor`. A full foreground fill requires
explicit `FgFillColor`, `FgFillEndColor`, `FgFillStopColor0..4` updates; retain
gradient enums unless separately qualified. Legacy and native deletion both
refuse unresolved macro/event/reference/opaque dependencies. Do not bypass them.
Dense HMI state indices remain separate from produced PLC codes. Native register
writers qualify BOOL/INT/DINT/REAL; logical TIME/64-bit validation is not a writer
or permission to attach another tag. Keep visible macro text distinct from
parsed operands. Resource-bank ownership inspection does not qualify alarm,
history or tag constructors. Read `tool_support` in capabilities; exposed vendor
compile/simulation/transfer routes remain explicitly unimplemented.

After interruption, locate the operation through `inspect_native_plan` or
`inspect_artifact_plan`; use `inspect_operation` and `reconcile_operation`.
Recover applied in-memory plans with the exact original source and
`restore_candidate`, not by replay. To recover a creation response loss, repeat
the same **proposal** pins/path in a fresh `create_project` session, inspect its
existing operation and reconcile. This never copies again. Completed descriptor
claims, exact bytes, current source/profile and template qualification are all
required; RUNNING alone is insufficient. Historical success does not prove a
current replaced file. Preserve unknown effects and report the failed gate.

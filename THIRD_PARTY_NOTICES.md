# Third-party license scope

The Apache-2.0 grant applies to original umbrella source and documentation. It does not replace licenses or notices of dependencies, Python, wheels, vendor software, external backends or customer artifacts.

The pinned DOP-B 0.2.0 release is maintained independently. Its current source release has no top-level LICENSE or license metadata. It is therefore **not yet approved for public redistribution** under the umbrella's Apache-2.0 declaration. A separately licensed new release and dependency/asset notice inventory must be produced and pinned before public bundled release. Existing private artifacts are not retroactively relabeled.

The independent DIAScreen owner has received the Apache-2.0 licensing instruction. Its final license and notices must be verified with the delivered artifact. Historical upstream code with unclear licensing remains excluded.

Retain the exact license and NOTICE files supplied by each bundled wheel, runtime and backend. A dependency pin or successful test is not a redistribution-license review. No blanket claim is made that every bundled component uses Apache-2.0.

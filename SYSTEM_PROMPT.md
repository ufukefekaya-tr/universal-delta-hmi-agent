# Canonical policy

Build a portable, file-only Universal Delta HMI Agent. The umbrella coordinates isolated family backends; it does not merge their parsers, native formats, profiles, projects, credentials or qualification evidence.

1. DOP-B/DOPSoft and DOP-100/DIAScreen are explicit routes. No extension renaming, automatic fallback, or family-wide support claim. Report exact source/model/editor/profile/feature evidence. A missing backend stays unavailable.
2. Never use Computer Use, IDE automation, PLC connections, force, uploads/downloads or panel operation. Native generation, vendor compilation and physical acceptance are separate evidence levels.
3. Trusted host configuration fixes runtime, module, source pins and separate workspace/profile/state roots. A job cannot change the launch command, grant approval or widen its scope. Processes are isolation boundaries, not an OS security sandbox.
4. Preserve source repositories. Work from pinned, licensed release artifacts or separately authorized local components. Do not copy customer projects, PLC tags, logos or machine-specific scripts into the generic implementation. Unclear third-party licensing blocks redistribution, not read-only inventory.
5. Record every discovered feature in the migration ledger. Distinguish implemented, source-bound, preserved-only, unqualified and blocked. A report row is not implementation. Do not omit features merely because they are difficult.
6. Native candidates require existing backend approval, address/type/behavior/source contracts and saved-file verification. Maintained is not momentary; requests are not physical feedback; stale data is not healthy. Unknown fields remain preserved or cause explicit refusal.
7. Use independent technical review and a final omission review against source manifests. Production UI requires two sequential aesthetic reviews and user approval, unless separately scoped trusted headless authority applies. This infrastructure task creates no customer UI.
8. Keep runtime paths relative or generated on the destination host. Keep local source locations in ignored task state. Install only pinned/hash-verified dependencies from official or already authorized release material. Missing hardware cannot be downloaded; report the exact unavailable acceptance stage.
9. Before mutations, freeze source hashes, allowed paths, baseline and control epoch. Epoch is SHA256 of AGENTS.md, SYSTEM_PROMPT.md, INDEX.md in that order, each UTF8 relative path + NUL + raw bytes + NUL. Resume requires rereading checkpoint and guard verification. Never hide failing checks.
10. Single writer per file. Checkpoints and commits belong to root. A control policy change needs a separate explicit policy transition. Keep useful progress updates brief, with no more than 60 seconds silence during active work.

Completion means the advertised scope has actual tests and exact-artifact review. Framework readiness, backend feature migration, vendor qualification and physical qualification are separate goals. No agent consensus substitutes for evidence.
